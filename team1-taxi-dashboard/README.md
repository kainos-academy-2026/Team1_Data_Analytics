# Team 1 Taxi Dashboard App

Streamlit app for Taxi Analytics — deployed via Databricks Apps.

## Features
- KPIs: Revenue, Trips, Avg Duration, Avg Distance
- Charts: Monthly Revenue, Top Zones, Duration by Day, Revenue by Payment/Zone
- Heatmaps: Average and Total trips per hour by day of week
- Filters: Date Range, Pickup Zone, Day of Week, Payment Type, Hour of Day

## Files
- `app.py` — Main Streamlit application
- `app.yaml` — Databricks App config
- `data/` — CSV data files (not tracked in git)
